# Stitch screen references

This directory contains the user's Stitch export for the Paytm AI Business Partner screens. Each screen folder has the supplied `screen.png` and `code.html`; `executive_precision/DESIGN.md` contains the exported design notes.

The files are retained as design references. The native implementation lives in `mobile/app/` and `mobile/src/`; the supplied HTML is not loaded or executed by the Android app.
